# School Transport Portal: upload-ready version

Upload every file in this folder to a new GitHub repository, then deploy it on Render.

- Start command: `python school_portal.py`
- Build command: `pip install -r requirements.txt`
- Environment variable: `ADMIN_PASSWORD` (your admin sign-in password)

On Render's free plan the database resets whenever the server restarts, so this is a demo setup.
